# **Laboratório de Ideias**

## Versão 2

Esta é a segunda versão do site do Laboratório de Ideias, versão esta que estou desenvolvendo com Next.js, React e TypeScript. Ideia esta surgiu-me devido minha vontade de praticar e aperfeiçoar minhas habilidades de desenvolvimento, trazendo uma nova visão desde a última versão.


## Versão 1

A versão 1 deste site fora desenvolvido em PHP, executado usando o XAMPP, pois não havia nada mais simples e prático para o desenvolvimento do site no momento do início, sem contar a limitação de meu conhecimento naquela época.


## Proposta

Agora, com mais experiência e conhecimento arrecadados, retorno à esse projeto para propor uma forma mais inovadora e mais profissional de desenvolvimento do site do Laboratório de Ideias.
